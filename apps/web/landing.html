Know every listing before you publish it.

ListGuard reads photos and rough descriptions, then grounds each attribute in evidence you can audit.

Open the dashboard How review works

The reviewer sees proof, not predictions.

Each attribute arrives with a confidence score, the exact text or image region behind it, and the model version that produced it. Anything unsupported is marked abstained, never stated as fact.

From upload to decision in four passes.

1

Upload

Sellers drop in photos plus a rough description. No forms, no taxonomy homework.

2

Ground

Brand, category, color, and condition are extracted with confidence, or the system abstains.

3

Compare

Near-duplicate search plus a calibrated price interval, with the matches shown.

4

Decide

Publish, warn, or send to human review. Corrections append as new events; predictions are never edited.

Evaluation

Measured, never claimed.

Retrieval is scored with standard ranking metrics. Confidence is calibrated. Latency is timed. When a number appears in this project, it was measured on a real run.

Recall at K
Share of true duplicates found in the top results.
MRR and mAP
Rank-aware scoring across the full result list.
Calibration
Confidence checked against outcomes, not vibes.
Latency
Timed per call from p50 to p99, with query plans.

Every decision keeps its receipts.

  • Evidence stays attached. Text spans, image regions, and sources travel with each attribute.
  • Versions are pinned. Any result reproduces from its stored model version.
  • History is append-only. Accepts, rejects, and corrections accumulate; nothing is overwritten.
